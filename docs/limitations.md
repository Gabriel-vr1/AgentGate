# Submission limitations

- Three specialized stages call a Foundry model through the project Responses
  API. They are not persistent Foundry agent resources and have no portal agent
  run records created by this application.
- Tracing is local application JSON. There is no Application Insights export,
  Azure Monitor integration, portal trace verification, or deterministic-tool
  span coverage. The saved failure trace is explicitly mocked.
- Evaluations run locally against controlled labels. No Foundry evaluation
  dataset/job, service evaluator score, or explanation-quality score is claimed.
- Model explanations are advisory and can be wrong. The saved safe-case prose
  refers to tests that are not in Python's selected-test list. The authoritative
  decision records do not inherit those assertions. Zero unsupported model
  claims has not been established.
- Reviews read stored synthetic assurance fixtures. They do not run candidate
  trading-agent tools, execute fresh assurance tests, or prove real safeguards.
- The fixed policy/risk mapping is designed for these cases. Unknown semantic
  capabilities are not universally classified. Some failure/evidence labels
  reuse the unsafe manifest; the measured recall is seeded-case recall only.
- The cloud judge must match the Python floor exactly. Verdict strengthening,
  richer uncertainty fields, data-source inventory, and result-ID citations
  from the blueprint are not implemented.
- The reviewer is a single-user loopback server with fixed scenarios. It is not
  a hosted production service or arbitrary manifest-upload application.
- Browser automation exposed no browser, so visual layout, interactive download
  and end-to-end browser click testing remain unverified. HTTP behavior and
  JavaScript syntax are checked; this is not equivalent to browser visual QA.
- No real trading, live data, deployment automation, MCP, CI/CD, new Azure
  resources, additional agents or industries were added.
- The owner must record the demo and submit it. This repository contains no
  submission receipt and makes no claim that every original blueprint or
  external challenge requirement is fulfilled.
